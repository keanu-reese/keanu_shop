APPLICATION CONTROL

Settings & backup.

Umbrel service health, centralized storage, and security practices.

Umbrel backend

Browser SSH and on-demand network diagnostics

Checking…

This self-hosted Docker service runs on your Umbrel. SSH opens as an interactive terminal inside your browser. The SSH connection originates from Umbrel, not your Windows workstation. An initial host-key prompt must be checked against a trusted fingerprint.

RDP: downloads a standard .rdp file for your local Remote Desktop client. Network checks and diagnostics are opt-in and are never scheduled automatically.

Import & export

Back up your centralized inventory

Data is stored on Umbrel in a persistent Docker volume and shared across signed-in browsers. Export a JSON backup for safekeeping or migration.

Import replaces data in the selected dashboard only. Revision checks prevent silent overwrites when another user has saved newer data.

Account security

Change your personal dashboard password

Changing your password signs you out on all devices.

Operational safety

Suggestions for keeping the workstation secure

  • SSH uses OpenSSH in a container terminal; passwords can be typed at the remote host prompt, but are not saved by NETOPS. For keys, use the persistent container SSH directory.
  • This dashboard requires a login. Restrict LAN/VPN access and use HTTPS for remote use; do not publicly expose this management endpoint.
  • Open untrusted management UIs only over trusted networks or VPN.
  • Do not save secrets in bookmarks, notes, or command snippets.
